# Vyntyra Internship – Client vs. Server in Real Life

## Task
Client vs. Server in Real Life

## Objective
To understand what happens between entering a URL and rendering a web page, including DNS, TCP/IP, HTTP requests, server responses, and browser parsing.

## Practical Audit
The Swiggy website was used for the practical audit with Chrome DevTools.

### Observations
- HTTP Method: GET
- Status Code: 200 OK
- Total Request Time: 245.69 ms
- Server Response Waiting Time: 178.92 ms
